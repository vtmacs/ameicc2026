Overview 1: What Is SAKURA AI Engine?

What Is Generative AI?

Generative AI learns from large amounts of text and creates answers by predicting what comes next. Unlike search, it generates an answer rather than finding existing text.

  • Responses may vary even for the same question
  • It cannot answer from documents it has never received
  • This limitation leads directly to RAG

What Is SAKURA AI Engine?

SAKURA AI Engine is a secure and flexible API platform for building generative AI applications. Data processing is completed in data centers in Japan.

  • Multiple foundation models to choose from
  • Document management and RAG
  • Audio transcription, TTS, and image input

Understanding the Concept of a Model

A model is the brain of an AI system. Models differ in what they have learned, their size, and what they are good at.

Type Example Note
Smaller gemma-4-31B-it Lightweight and fast
Standard gpt-oss-120b Used in this class
Larger Kimi-K2.7-Code High performance

Available Models shows tags such as Coding, Multimodal, and Public Preview to help you choose the right model.

Overview 2: What Is an API?

An API is an interface that allows a program to call a service. Send a request in a defined format and receive a response in a defined format.

Four Things You Need to Define

Item Role Value in This Class
Endpoint Where to send https://api.ai.sakura.ad.jp/v1/chat/completions
Authentication Who sent it Account Token
Request What to ask Model name and prompt
Response Answer returned Text in JSON format

Everything you did in Playground also uses this API behind the scenes.

Hands-On 2: Run AI from the Command Line

Issue an Account Token and call AI from the WSL (Ubuntu) terminal using curl.

Required

  • Issue an Account Token
  • Store the token in an environment variable
  • Send a question to SAKURA AI Engine using curl
  • Extract the answer from the returned JSON
  • Edit the prompt and run the command again

Steps

  1. STEP 1: Issue an Account Token

    Select Account Tokens from the left menu, click Create Account Token, enter a name, and copy and save the displayed token. The token is shown only once.

  2. STEP 2: Store the Token in an Environment Variable

    Open the WSL (Ubuntu) terminal and run the command below. This saves you from pasting the token every time.

    export AI_ENGINE_TOKEN="<issued account token>"
echo $AI_ENGINE_TOKEN

    This setting remains active until you close the terminal. Run export again after reopening it.

  3. STEP 3: Ask a Question with curl

    Copy and run the following command. Check where the endpoint, authentication, request, and response are written.

    curl --location https://api.ai.sakura.ad.jp/v1/chat/completions \
  --header 'Accept: application/json' \
  --header "Authorization: Bearer ${AI_ENGINE_TOKEN}" \
  --header 'Content-Type: application/json' \
  --data '{
      "model": "gpt-oss-120b",
      "messages": [
        { "role": "user", "content": "Hello!" }
      ],
      "temperature": 0.7,
      "max_tokens": 200,
      "stream": false
    }'
  4. STEP 4: Edit the Prompt and Run Again

    Edit the messages part and run the command again.

      --data '{
      "model": "gpt-oss-120b",
      "messages": [
        { "role": "system", "content": "You are a helpful travel guide." },
        { "role": "user",   "content": "Recommend three famous tourist attractions in Thailand." }
      ],
      "max_tokens": 300
    }'

Request Parameters

Parameter Meaning
modelName of the AI model to use
messagesConversation content, including roles and messages
roleSpeaker role: user for user input; system for AI instructions
contentMessage text to send
temperatureControls response diversity
max_tokensMaximum response length
streamStreaming or non-streaming response mode

How to Read the JSON Response

The answer is in choices[0].message.content. usage shows the number of tokens consumed.

{
  "id": "chatcmpl-xxxxxxxx",
  "object": "chat.completion",
  "model": "gpt-oss-120b",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 12, "completion_tokens": 20 }
}

Extract Only the Answer

You can display only the answer text instead of the entire JSON.

curl -s --location https://api.ai.sakura.ad.jp/v1/chat/completions \
  --header "Authorization: Bearer ${AI_ENGINE_TOKEN}" \
  --header 'Content-Type: application/json' \
  --data '{ "model": "gpt-oss-120b",
            "messages": [{ "role": "user", "content": "Hello!" }] }' \
| python3 -c "import sys,json; print(json.load(sys.stdin)['choices'][0]['message']['content'])"

Optional

  • Change temperature and max_tokens to compare responses
  • Call the same API from Python

Python example:

import os, requests
url = "https://api.ai.sakura.ad.jp/v1/chat/completions"
headers = {
    "Authorization": f"Bearer {os.environ['AI_ENGINE_TOKEN']}",
    "Content-Type": "application/json",
}
payload = {
    "model": "gpt-oss-120b",
    "messages": [{"role": "user", "content": "Hello!"}],
    "max_tokens": 200,
}
res = requests.post(url, headers=headers, json=payload)
print(res.json()["choices"][0]["message"]["content"])

Common Errors and Solutions

Error Cause Solution
401 Unauthorized Token not passed correctly Check echo $AI_ENGINE_TOKEN and the space after Bearer
Command stops halfway Full-width quotation marks Use straight quotes, turn off IME, no space after backslash
Cannot connect / no response Network or proxy issue Check Wi-Fi and campus network restrictions

Overview 3: How RAG Works

What Is RAG?

RAG (Retrieval-Augmented Generation) searches registered documents before answering, then generates an answer grounded in those documents.

  • Answer based on registered documents
  • Answer information a general AI does not know
  • Show which documents were referenced
  • Cannot use unregistered information as evidence

Understanding Chunks

Registered documents are divided into sections of a specified token length. Each section is called a chunk.

  • Searches are performed by chunk
  • Only relevant sections are referenced
  • Supported formats: txt, pdf, html, docx, xlsx, md, etc.

Important: Billing Notice Before Registration

Registering documents incurs monthly charges based on the number of chunks until the document is deleted. These charges apply even when using the Foundation Model Free Plan.

You will not be charged directly in this class because we use a training environment. In actual use, make a habit of deleting documents after use.

Hands-On 3: Build a RAG Chatbot

Register the provided PDF with SAKURA AI Engine and compare the same question with and without RAG.

Required

  • Download and register the provided PDF
  • Ask a question without RAG and record the answer
  • Ask the same question with RAG and record the answer
  • Ask a question not covered by the document
  • Describe the difference in one sentence on the worksheet

Steps

  1. STEP 1: Download the Document and Place It in WSL

    Download the PDF from the link below, create a 01_AI_RAG folder in your WSL home directory, and copy the file there. Use File Explorer drag-and-drop for copying.

    Download Annual Report 2564 (PDF)

    cd ~
mkdir -p 01_AI_RAG

ls -l
  2. STEP 2: Register the Document

    Select Documents (RAG) from the left menu and click Add Document. Enter the name, file, embedding model, and chunk size, then upload. Wait until the status changes from pending to available.

  3. STEP 3: Run a RAG Query

    Open Documents (RAG), click Operation, select Query Search, enter the question below, and run.

    Explain KOSEN-KMITL and Monozukuri.

  4. STEP 4: Use RAG in Playground

    Open Playground, turn on the Document button at the bottom of the screen, set top_k and threshold with the gear icon, and submit the same question.

    Parameter Meaning
    tagsReference only documents with the selected tags
    top_kNumber of top-ranked chunks to retrieve
    thresholdVector-distance threshold (0–2)
  5. STEP 5: Compare Results Without and With RAG

    Ask the same question with the Document button off (without RAG) and on (with RAG). Also ask something not in the document, such as “Who will win the next FIFA World Cup?”

Optional: Run RAG via API

The same operations can be performed through the API.

1. Upload the document:

curl --request POST \
  --url https://api.ai.sakura.ad.jp/v1/documents/upload/ \
  --header 'Accept: application/json' \
  --header "Authorization: Bearer ${AI_ENGINE_TOKEN}" \
  --header 'Content-Type: multipart/form-data' \
  --form "file=@annual-report-2564.pdf"

2. Check the status:

curl -s --location 'https://api.ai.sakura.ad.jp/v1/documents/<document-id>/' \
  --header "Authorization: Bearer ${AI_ENGINE_TOKEN}" \
| grep -oE '"id":"[^"]*"|"status":"[^"]*"|"name":"[^"]*"'

3. Run a RAG query:

curl --request POST \
  --url https://api.ai.sakura.ad.jp/v1/documents/chat/ \
  --header 'Accept: application/json' \
  --header "Authorization: Bearer ${AI_ENGINE_TOKEN}" \
  --header 'Content-Type: application/json' \
  --data '{
      "model": "multilingual-e5-large",
      "chat_model": "gpt-oss-120b",
      "query": "Explain KOSEN-KMITL and Monozukuri.",
      "top_k": 3,
      "threshold": 0.6,
      "distance_type": "cosine"
    }'
Parameter Meaning
modelModel used for vectorization and embedding
chat_modelLLM used to generate the answer
queryQuestion in natural language
top_kNumber of top-ranked chunks to retrieve
thresholdVector-distance threshold (0–2)
distance_typecosine or l2
